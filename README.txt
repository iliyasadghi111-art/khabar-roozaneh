خبر روزانه — راهنمای انتشار اینترنتی

این بسته یک سایت فارسی راست‌چین با رنگ سرمه‌ای و سفید و پنل مدیریت جداگانه دارد.
برای اینکه خبرهایی که اضافه می‌کنید برای همه بازدیدکنندگان دیده شود، باید یک پایگاه داده آنلاین تنظیم شود.

مرحله ۱ — ساخت پایگاه داده رایگان
1) به https://supabase.com بروید و یک حساب بسازید.
2) یک پروژه جدید بسازید و رمز پایگاه داده را در جای امن نگه دارید.
3) از بخش SQL Editor فایل database.sql را باز/کپی کنید و Run بزنید.
4) از Project Settings > API مقدار Project URL و anon/public key را کپی کنید.
5) این دو مقدار را در فایل config.js جایگزین PASTE... کنید. کلید service_role را هرگز در سایت قرار ندهید.

مرحله ۲ — ساخت حساب مدیر
1) در Supabase به Authentication > Users بروید و Add user را بزنید؛ ایمیل و رمز خودتان را وارد کنید.
2) شناسه UUID کاربر را کپی کنید.
3) در SQL Editor این دستور را با UUID خودتان اجرا کنید:
   insert into public.site_admins(user_id) values ('UUID-اینجا');
فقط حسابی که در site_admins ثبت شده اجازه انتشار، ویرایش و حذف دارد. ثبت‌نام عمومی در سایت وجود ندارد.

مرحله ۳ — انتشار رایگان
1) به https://app.netlify.com بروید و وارد شوید.
2) پوشه khabar_roozaneh_site را پس از جایگزین‌کردن config.js به‌صورت پوشه یا فایل ZIP در Netlify منتشر کنید (Add new site > Deploy manually).
3) Netlify یک آدرس عمومی شبیه https://your-site-name.netlify.app می‌دهد.
4) آدرس اصلی برای همه: /index.html
   پنل مدیریت خصوصی: /admin.html

نکته‌ها
- برای تغییر خبرها وارد /admin.html شوید. پنل مدیریت جداست و در صفحه اصلی/OBS دیده نمی‌شود.
- خبرها در پایگاه داده آنلاین ذخیره می‌شوند و برای همه بازدیدکنندگان یکسان هستند.
- این نسخه خبرها را خودکار از خبرگزاری‌ها جمع‌آوری نمی‌کند؛ خودتان از پنل خبر اضافه می‌کنید.
- از رمز قوی و یکتا استفاده کنید. کلید anon در config.js برای مرورگر است؛ امنیت نوشتن را سیاست‌های database.sql اعمال می‌کنند.
- برای عکس، لینک مستقیم تصویر را وارد کنید. در مرحله بعد می‌توانیم آپلود مستقیم عکس را هم اضافه کنیم.
